## What Engram Cloud is not

- Not cloud-only — local SQLite is always the source of truth
- Not implicit sync-everything — `--all` is blocked in cloud mode; sync is per project
- Not SaaS — fully self-hosted, no vendor lock-in
- Not a replacement for the local binary — both runtimes coexist
